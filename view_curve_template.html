Notes

Drag to rotate, scroll to zoom, right-drag to pan. The camera icon above the plot saves a PNG. Click a legend entry to hide it.

Track frame: chainage s along the reference line, sideways offset d from it (left = +), and height Z as stored in the LiDAR file. The rails are 1.43 m apart in a track hundreds of metres long, so sideways and height are stretched; ×1 is true scale. Narrowing the window or hiding the point cloud keeps the shape of the box.

World: E and N as in the file with the origin subtracted (see the axis titles), true horizontal scale; only height is stretched.

Lines are the Catmull-Rom curve through the control points (circles); the red line is the centreline, midway between the rails. The purple bar is the cursor. Z is relative to the sensor, so the LiDAR track's own rails stay nearly flat.
